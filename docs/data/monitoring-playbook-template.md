# Daily Monitoring — Playbook Capture Template

Fill ONE block per site while doing the daily round (16 EPL links in
`ticket-monitor-sources.md`). Deliver by: pasting screenshots+notes in chat, a shared
Google Drive folder, or via Cowork. Claude reads images/text — NOT raw video.

The output of each block becomes the site's automated parser + the scanner's daily checklist.

---

## Per-site block (copy this for each site)

```
CLUB:                 <e.g. Arsenal>
URL:                  <the link>
LOGIN NEEDED?         yes / no      (if yes: what is visible WITHOUT logging in?)
WHERE THE ON-SALE DATE SHOWS:   <point to / screenshot the exact area of the page>
"SALE IS OPEN" WORDS:  <e.g. "General Sale", "On sale now", "Buy now">
MEMBERS-ONLY vs GENERAL SALE — how you tell them apart:
WHAT YOU IGNORE:      <hospitality, sold-out rows, etc.>
YOUR DECISION RULE:   <e.g. "if General Sale for a big club → log to calendar + buy">
SCREENSHOT(S):        <attach>
FREQUENCY:            <how often this club opens sales / when you check it>
```

---

## Worked example (what a good filled block looks like)

```
CLUB:                 Chelsea
URL:                  https://www.chelseafc.com/en/all-on-sale-dates
LOGIN NEEDED?         no — the on-sale dates are public on this page
WHERE THE ON-SALE DATE SHOWS:   a table listing each match with "Members sale" and
                       "General sale" date columns
"SALE IS OPEN" WORDS:  "General Sale", "On Sale", the date being today or past
MEMBERS-ONLY vs GENERAL SALE:  two separate columns; I want the General Sale date
WHAT YOU IGNORE:      hospitality packages, corporate
YOUR DECISION RULE:   when a big-club home game hits General Sale → log date + buy
SCREENSHOT(S):        [attached]
FREQUENCY:            new fixtures added ~monthly; check weekly
```

---

## Tips for a fast, useful round
- Do the sites in your normal order — the order itself is signal (what you check first = highest value).
- One screenshot per site is enough if it frames where the date lives.
- Note the tricky ones loudest: which sites need login, which hide the date, which lie/are stale.
- Don't worry about the missing 5 clubs (West Ham, Brighton, Bournemouth, Burnley, Sunderland) —
  add their links + blocks when you have them.
